## 1. Objective

Deliver a **single-brand, production-ready online store** for **Afiya Leathers** with a matching **admin panel**, configured for the Client’s identity, leather catalogue, and business accounts. This is a **dedicated deployment** for Afiya Leathers (not a shared multi-tenant SaaS across brands).

---

## 2. Deliverables — included

### 2.1 Customer website (storefront)

- Home, shop / catalogue with department filters (Men, Women, Bags, Accessories, etc.)  
- Product detail, cart, checkout  
- About & Contact pages (Afiya Leathers copy / Client-approved updates)  
- Wishlist and customer auth flows as available in the platform  
- Mobile-responsive layout  
- Brand theme: cognac / brass / parchment, logos, favicon  

### 2.2 Admin panel

- Secure admin login  
- Product add / edit / list (images, price, categories, departments)  
- Category tree management  
- Order viewing & status updates  
- Coupon management  
- Heroes / site settings / Instagram promos as supported  
- One guided training session (**≈ 1 hour**, online or in person)

### 2.3 Configuration & launch

- Afiya Leathers branding applied to the deployment  
- Razorpay configuration (Client’s keys; live key ID already used in project env)  
- Transactional email via **Resend** (OTP, resets, order mail) after domain DNS is verified  
- Shiprocket shipping hooks when Client credentials are active  
- Deploy frontend, admin, and API to agreed hosting  
- Hand over admin credentials and short usage note  
- Policy page placeholders (Privacy / Shipping / Refund) for Client approval
